# Video Auditor — мультимодальный ML-сервис контроля качества AI-видео

Учебный проект курса «Машинное обучение: от технической базы до создания ИИ-продукта» (модуль «My First Data Project»).

**Цель проекта:** разработать ML-сервис для проверки качества AI-сгенерированных видео, выявления дефектов и формирования рекомендаций по их исправлению. Сервис планируется использовать как самостоятельный инструмент и как компонент автоматизированного производства видео.
