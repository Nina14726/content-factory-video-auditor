# Video Auditor — ML-сервис режиссёрского анализа и контроля качества AI-видео

Учебный проект курса «Машинное обучение: от технической базы до создания ИИ-продукта» (модуль «My First Data Project»).

**Цель проекта:** разработать ML-сервис для режиссёрского анализа коротких AI-сгенерированных видео перед публикацией или доработкой. Video Auditor оценивает историю, хук, композицию, движение, монтаж, соответствие первоначальному замыслу и явные визуальные дефекты; формирует разбор с таймкодами, конкретными рекомендациями и решением `approved` / `revise` / `manual_review`. В первом прототипе автор загружает ролик через веб, читает отчёт и отмечает, видна ли указанная проблема и подходит ли правка. Отчёт сохраняется в JSON. Подключение агентов через MCP запланировано после пилота. Исправление, публикация и анализ звука выходят за рамки прототипа.
