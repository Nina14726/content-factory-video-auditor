# Video Auditor — ML-сервис режиссёрского анализа и контроля качества AI-видео

Учебный проект курса «Машинное обучение: от технической базы до создания ИИ-продукта» (модуль «My First Data Project»).

**Цель проекта.** Помочь англоязычным авторам коротких AI-видео проверять ролики в привычном агентном процессе. В первом прототипе агент автора передаёт готовый клип через MCP вместе с доступным сценарием или исходным промптом. Video Auditor возвращает JSON: статус `approved`, `revise` или `manual_review`, таймкод, наблюдаемую проблему, объяснение и конкретную правку. Для сцены, требующей перегенерации, целевой результат — готовый промпт с сохранением авторского замысла. Автор получает выводы прямо в своём агенте. Генерацию и публикацию выполняют внешние инструменты. Аудитор оценивает визуальный ряд.
