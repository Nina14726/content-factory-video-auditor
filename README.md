# Video Auditor — ML-сервис режиссёрского анализа и контроля качества AI-видео

Учебный проект курса «Машинное обучение: от технической базы до создания ИИ-продукта» (модуль «My First Data Project»).

**Цель проекта:** разработать ML-сервис для режиссёрского анализа коротких AI-сгенерированных видео перед публикацией или доработкой. Video Auditor оценивает историю, хук, композицию, движение, монтаж, соответствие первоначальному замыслу и явные визуальные дефекты; формирует разбор с таймкодами, конкретными рекомендациями и решением `approved` / `revise` / `manual_review`. Человек получает отчёт через веб-интерфейс, AI-агенты — структурированный результат и инструкции через MCP. **Сам аудитор не исправляет, не перегенерирует и не публикует видео**: это делает автор или внешний агент. Проверка звука не входит в текущий прототип.
